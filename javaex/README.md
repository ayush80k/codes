# Java Experiments

| # | Experiment | Folder |
|---|-----------|--------|
| 1 | AWT program to create check boxes | `01-awt-checkboxes` |
| 2 | Swing program to make components | `02-swing-components` |
| 3 | JDBC application for database operations | `03-jdbc-application` |
| 4 | Socket program for client-server communication | `04-socket-client-server` |
| 5 | RMI application (client sends operator and operands) | `05-rmi-calculator` |
| 6 | Servlet to display "Hello World" | `06-servlet-hello-world` |
| 7 | Servlet for user registration | `07-servlet-registration` |
| 8 | JSP user login (static & dynamic database) | `08-jsp-login` |
| 9 | JSP to display student grade | `09-jsp-student-grade` |
| 10 | Case study on Java Bean | `10-case-study-javabean` |
| 11 | Case study on Enterprise Java Beans | `11-case-study-ejb` |

## Requirements
- JDK 11+ (`javac -version`)
- Apache Tomcat 10+ (experiments 6-10)
- MySQL + Connector/J jar (experiments 3 and 8)
- WildFly / GlassFish / TomEE (experiment 11)

Each folder has its own `README.md` with exact run commands.
